Cách hoạt động: trang này cho phép bạn chỉnh nội dung trên trình duyệt và xuất ra file site-data.json. Vì GitHub Pages là hosting tĩnh, file sau khi xuất cần được tải lên repository để cập nhật website. Không nhập mật khẩu hoặc token GitHub vào trang này.
Đưa thay đổi lên website: bấm “Xuất site-data.json” → tải file về → vào GitHub repository → Add file → Upload files → kéo file site-data.json vào → Commit changes. GitHub Pages sẽ tự triển khai sau khi repository cập nhật.
