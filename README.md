# Sơn Nhà Đẹp Hoàn Nguyễn — V4

Website GitHub Pages + trang quản trị nội dung.

## Quản trị
Mở `/admin.html`.
Chỉnh sửa nội dung, sau đó chọn **Xuất site-data.json**. Tải file `site-data.json` lên thư mục gốc repository bằng GitHub → Add file → Upload files → Commit changes.

## Ảnh
Có thể dùng URL ảnh công khai trong các trường ảnh. Với ảnh riêng, tải ảnh lên `assets/` rồi dùng đường dẫn tương đối, ví dụ `assets/cong-trinh-01.jpg`.

## Bảo mật
Không nhập Personal Access Token hoặc mật khẩu GitHub vào trang quản trị tĩnh.
